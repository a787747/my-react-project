## Import mechanics

Implementation: `scripts/import_epe_2026.py`

The script:

1. resets the malformed workbook dimensions;
2. validates 88 unique emails and all approved department values;
3. resolves every manager name, including manual Cem;
4. rejects unresolved grades, managers, duplicate emails, and manager cycles;
5. generates a transaction using a temporary staging table;
6. inserts only missing departments, grades, and users;
7. updates existing users only when tracked values are distinct;
8. links managers in a second conditional update;
9. never imports or updates `password_hash`.

The generated SQL is intentionally psql-specific (`ON_ERROR_STOP`) and must be
executed with psql, not pasted into a GUI SQL client.

The import was first executed twice against a restored copy of the pre-import
database. Both the semantic data and permanent sequence values were unchanged
on the second run.
