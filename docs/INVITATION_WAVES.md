## 4. Who has registered

**Admin view:** Сотрудники (`AdminUsers`). Each row now shows «Зарегистрирован» / «Не зарегистрирован». The API field is `is_registered` (`password_hash IS NOT NULL`); the hash itself is not returned.

**SQL (read-only):**

```sql
SELECT
  count(*) FILTER (WHERE password_hash IS NOT NULL) AS registered,
  count(*) FILTER (WHERE password_hash IS NULL) AS not_registered,
  count(*) AS total
FROM performance_db.users;

SELECT u.full_name, u.email, u.role, d.name AS department
FROM performance_db.users u
LEFT JOIN performance_db.departments d ON d.id = u.department_id
WHERE u.password_hash IS NULL
ORDER BY d.name, u.full_name;
```
