## Если что-то не так

**Кнопки «Выключить» в экране нет.** Второй период, на который можно переключиться, закрыт. После первой оценки система сама запретит смену периода (ошибка 409).

Остановить кампанию можете только вы через этот чат: напишите «выключи H1». Списки снова станут пустыми, писать оценки будет нельзя.

Позвонить некому, кроме вас: **второй учётной записи с правами admin сегодня нет.** До 31 августа решите, кто это будет, и скажите — заведём. Пока единственный человек, который может нажать «Активировать», — вы.

Не создавайте новый период «на всякий случай» и не трогайте Annual 2025.

## Чего не делать, пока идёт кампания

- Не меняйте **критерии, веса, коэффициенты**. Экраны «Критерии» и «Коэффициенты» после активации всё равно откажут.
- Не меняйте **классификацию** (`general` / `project`) после первой отправленной оценки — система вернёт 409, это не поломка.
- Не переключайте период и не создавайте новый, чтобы «починить» что-то.
- Не просите включить старый маршрут очистки тестовых оценок. Его нет.

Кто уже зашёл в порталь:

- **Администрирование → Сотрудники.** В строке бейдж «Зарегистрирован» / «Не зарегистрирован».
- Сейчас должен быть **один** зарегистрированный — вы. К 31 августа лучше, чтобы волна 1 (менеджеры, C-level, HR) уже была с бейджем «Зарегистрирован».

Если нужны точные числа, этот запрос можно выполнить у того, у кого есть доступ к базе (не вам в интерфейсе):

```sql
SELECT
  count(*) FILTER (WHERE password_hash IS NOT NULL) AS registered,
  count(*) FILTER (WHERE password_hash IS NULL) AS not_registered,
  count(*) AS total
FROM performance_db.users;
```
