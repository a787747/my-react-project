## 4. How to recompute these md5 sums

Read-only. Run against whatever database is being checked:

```sql
SELECT md5(string_agg(t, E'\n' ORDER BY t)) FROM (
  SELECT concat_ws('|', id, title, target_audience, weight, c_level_only, selfassesment, for_manager, is_active) AS t
  FROM performance_db.criteria WHERE is_active = true) x;   -- criteria

SELECT md5(string_agg(t, E'\n' ORDER BY t)) FROM (
  SELECT concat_ws('|', criteria_id, score_level, coefficient) AS t
  FROM performance_db.score_coefficients) x;                -- score_coefficients

SELECT md5(string_agg(t, E'\n' ORDER BY t)) FROM (
  SELECT concat_ws('|', id, code, coefficient, coalesce(description,'')) AS t
  FROM performance_db.grades) x;                            -- grades
```

The combined sum is `md5(criteria_md5 || score_coefficients_md5 || grades_md5)`.
